## 병합 전 고쳐야 할 것 (Important)

### I-1. `sw.js` — 오프라인에서 루트 주소로 열면 백지 (5분)

`FILES` 에 `'index.html'` 은 있지만 `'./'` 이 없다. `https://…/reservation/` 처럼 파일명 없이 들어오면 캐시 미스 → 오프라인에서 에러 페이지.
계획서 완료 기준 "비행기 모드에서도 앱이 열린다"가 통과하지 못한다.

```js
const FILES = [
  './', 'index.html', 'customer.html', 'settings.html', 'style.css',
```
+ `CACHE` 를 `'reservation-v2'` 로 올린다.

### I-2. `sw.js` — 배포해도 새 버전이 폰에 안 들어간다 (5분)

`skipWaiting`/`clients.claim` 이 없어 새 서비스 워커가 앱 완전 종료 때까지 대기한다. 홈 화면 PWA는 몇 주씩 안 죽으므로 그동안 구버전이 계속 뜬다.

**설계 문서 7장이 PWA를 고른 이유가 "고치면 즉시 반영"인데 지금 코드는 정반대로 동작한다.**

```js
self.addEventListener('install', (e) => {
  self.skipWaiting()                                    // ← 추가
  e.waitUntil(caches.open(CACHE).then((c) => c.addAll(FILES)))
})

self.addEventListener('activate', (e) => {
  e.waitUntil(
    caches.keys().then((keys) =>
      Promise.all(keys.filter((k) => k !== CACHE).map((k) => caches.delete(k)))
    ).then(() => self.clients.claim())                  // ← 추가
  )
})
```

### I-3. 아이폰 설치 시 헤더가 상태바에 겹친다 (2분)

세 HTML이 `viewport-fit=cover` 를 선언했는데 CSS에 `env(safe-area-inset-*)` 처리가 하나도 없다. 설치 후 첫 화면에서 바로 보인다.

가장 싼 수정: 세 HTML에서 `, viewport-fit=cover` 를 지운다. 이 앱은 전체화면 배경을 안 쓰므로 cover의 이득이 없다.

### I-4. 지난 날짜로 저장하면 조용히 사라진다 → 중복 입력 유발 (3분)

홈은 `date >= today` 만 그리는데 폼은 과거 날짜를 막지 않는다. 저장했는데 화면에 변화가 없으니 사용자는 "저장이 안 됐다"고 판단하고 다시 넣는다 → **손님 이력에 같은 방문이 두 번 쌓여 방문 횟수·평균 주기가 틀어진다.**

앱의 유일한 존재 이유가 손님 이력이므로 조용한 중복은 값비싸다.

`js/home.js` submit 핸들러:
```js
  const saved = store.add({ ... })
  render()
  if (saved.date < todayISO()) alert('저장했습니다. 지난 날짜라 목록에는 안 보이고 손님 이력에만 남습니다.')
```

### I-5. 손님 이력에 도달할 길이 하나뿐 — 앱의 존재 이유가 잠겨 있다 (판단 필요)

`customer.html` 로 가는 입구는 홈의 이름 링크 단 하나인데, 홈은 다가올 예약만 그린다.
→ **다가올 예약이 없는 손님의 이력은 앱 안에서 열 수 없다.**

그런데 이력을 보고 싶은 순간은 *손님에게 전화가 왔을 때*이고, 그때 그 손님에게는 다가올 예약이 아직 없다. 순서가 거꾸로다.

여기에 겹치는 문제: 이름 칸이 자유 입력이고 기존 이름을 제안하지 않는다. `byCustomer` 는 완전 일치 비교라 "화선언니"/"화선 언니" 오타 한 번이면 **이력이 조용히 두 개로 쪼개진다.** 사용자는 알아차릴 방법이 없다.

**리뷰어 권고:** datalist(오타 방지)는 지금 넣고, 손님 목록 화면은 별도 작업으로 1단계 마무리 전에 추가.

```html
<input type="text" id="f-name" list="knownNames" autocomplete="off">
<datalist id="knownNames"></datalist>
```
```js
// 이미 있는 손님 이름을 제안한다 — 오타 하나로 이력이 쪼개지는 걸 막는다
const names = [...new Set(store.list().map((r) => r.customerName).filter(Boolean))]
document.getElementById('knownNames').append(...names.map((n) => {
  const o = document.createElement('option'); o.value = n; return o
}))
```
